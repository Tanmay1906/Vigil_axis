# VIGIL-AXIS

Full-stack cyber forensics ecosystem.

## Architecture
- **Backend:** Flask Rest API handling logic and orchestrating requests.
- **Frontend:** React + Vite + Tailwind
- **Blockchain:** Hardhat + Solidity for immutable evidence ledger.
- **Triage Scripts:** Python scripts for log/packet extraction.
- **Shared:** Common schemas and types.
- **Docs:** System documentation.

> **Note**: This monorepo implements a strict separation of concerns and single responsibility principle.
